## 正文（可复制）

最近让 AI 带我读代码，发现一个很具体的问题：

我想知道代码怎么跑起来，它开始讲 runtime、context、依赖注入。追问一个词，又冒出几个新词。最后 TypeScript 聊了很久，最初想看的代码还没接上。

于是我把自己反复提的要求整理成了一个 Skill，叫「循循 / xunxun」。

先说它是什么。Skill 就是一套 AI 可以读取的工作指引。循循用来讲概念、读文件、带读代码库。

我的要求其实很简单：先把主线讲明白；新名词别默认我懂；需要补前置知识就补，补完记得带我回来。发现我没理解，先看看是不是讲错了、漏答了，再考虑换个例子。

安装后可以直接说：

“用 xunxun 带我读这个代码库，先从一次用户请求的入口，讲到最终结果。”

“我还是不懂。类型删掉之后，谁来检查输入？”

如果有一种讲法你想以后也用，可以直接要求它记住。偏好和可选的项目学习进度保存在本地，没有另做一个账号系统。

我也做了对比测试。旧版在 45 组配对里，模型裁判偏好循循 19 次、默认回答 12 次，其余打平。某些题能讲得更清楚，某些题也会讲重。原始回答和不足都放在仓库里了；目前还没证明长期学习效果。

GitHub 搜索：stveshawn1/xunxun-skill

用支持 Skills 的 AI 工具，也可以直接把仓库地址发给它，让它帮你安装。终端命令在仓库首页，装好后拿一个你真的没弄懂的问题试试。

你有没有遇到过那种“答案看着很完整，自己还是没懂”的时刻？评论区留一个你卡住的问题，也欢迎关注，继续看循循的后续改动和讲解对比。

## 发布与承接

仓库 README 是安装和案例入口。第一篇笔记只讲学习过程中的卡点；后续可以逐篇展示真实问题的讲解对比，让读者看到具体变化。
