不是。**借方不等于增加，贷方也不等于减少。**

借方和贷方首先只是记账位置：

- 借方（Debit）：账户左边
- 贷方（Credit）：账户右边

到底表示增加还是减少，取决于账户类型：

| 账户类型 | 增加记 | 减少记 |
|---|---|---|
| 资产 | 借方 | 贷方 |
| 费用 | 借方 | 贷方 |
| 负债 | 贷方 | 借方 |
| 所有者权益 | 贷方 | 借方 |
| 收入 | 贷方 | 借方 |

最容易记住的原理来自扩展后的会计等式：

> **资产 + 费用 = 负债 + 所有者权益 + 收入**

左边项目通常借增贷减，右边项目通常贷增借减。

用 `source.md` 里的例子看：

1. 赊销商品

客户还没付款：

- 应收账款（资产）增加 → 借方
- 销售收入增加 → 贷方

这里借方和贷方都代表“增加”，只是增加了不同类型的账户。

2. 后来收到货款

- 现金（资产）增加 → 借方
- 应收账款（资产）减少 → 贷方

这是同一类资产内部转换，因此看起来是“一增一减”。

3. 用现金购买机器

- 机器设备（资产）增加 → 借方
- 现金（资产）减少 → 贷方

同样只是把一种资产换成另一种资产，并没有立即产生等额费用。

4. 偿还欠款

- 应付账款（负债）减少 → 借方
- 现金（资产）减少 → 贷方

这时借方和贷方对应的账户余额都在减少：借方减少负债，贷方减少资产。

所以稳定的判断顺序是：

> **先判断是什么账户，再判断它增加还是减少，最后决定记借方还是贷方。**

不要直接问“这笔钱是进还是出”。现金流入、现金流出和借贷方向不是一回事——只有针对“现金这个资产账户”时，现金增加记借方、现金减少记贷方。复式记账要求的是每笔业务**借方金额合计等于贷方金额合计**，并不要求一边代表增加、另一边代表减少。
