# Adaptive immunity source snapshot

Source snapshot date: 2026-09-03. The following facts are condensed from NCBI Bookshelf chapters cited below.

Before exposure, receptor-gene rearrangement generates many B- and T-lymphocyte clones with different antigen receptors. Each clone has one specificity. Antigen binding selects a pre-existing matching clone; activation causes proliferation and differentiation into effector and memory cells.

B-cell receptors can bind antigen directly. T-cell receptors ordinarily recognize a foreign peptide bound to a self MHC molecule. For a naive T cell, recognition alone is generally insufficient: a professional antigen-presenting cell must also provide costimulation for activation and clonal expansion.

Most effector cells disappear after a primary response. Some antigen-specific cells become long-lived memory cells. A later encounter with the same antigen starts from a larger antigen-specific population whose memory cells respond more readily, producing a faster and stronger response. This memory remains antigen-specific and is not explained solely by persistent circulating antibody.
